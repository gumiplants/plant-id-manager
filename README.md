# 植物株ID管理システム (Plant ID Manager)

アガベ、パキポディウム、塊根植物、サボテンなどを1株ずつ個別管理するための、シンプルで軽量なWebアプリケーションです。

---

## 🚀 起動方法

プロジェクトフォルダ内にある **`start.bat`** をダブルクリックしてください。
- ファイルの場所: `C:\Users\kei_i\.gemini\antigravity\scratch\plant-id-manager\start.bat`
- 開発サーバーが自動で立ち上がり、既定のブラウザで **`http://localhost:5173`** が自動的に開きます。

---

## 🛑 サーバーの停止方法
- `start.bat` で開いた黒いコマンドプロンプト画面を「×」で閉じるか、キーボードで `Ctrl + C` を押してください。
- または、フォルダ内の **`stop.bat`** をダブルクリックすることでも安全に停止できます。

---

## 🌿 主な機能と管理項目
1. **管理項目**
   - **管理ID**: `AGV-001`, `CDX-001` 等（手動入力または自動採番補助ボタン対応）
   - **植物名・品種名**: アガベ・チタノタ '白火焔'、パキポディウム・グラキリス等
   - **血統・ナーセリー名**: 台湾株、実生株、イベント名等
   - **入手日**: 日付ピッカー選択（経過日数も自動計算）
   - **用土配合**: 自由記述 ＋ ワンクリック配合チップ
   - **現在の鉢サイズ**: 自由記述 ＋ ワンクリック鉢サイズチップ
   - **メモ**: 育成環境、照度、水やりサイクル等の自由記述
2. **一覧表示**
   - テーブル形式 ⇔ カード形式 の切り替え対応
   - 管理ID・植物名等のインクリメンタルリアルタイム検索
   - 並び替え（ID順、入手日順、登録順等）
3. **データ保存・バックアップ**
   - ブラウザの LocalStorage に自動永続化
   - JSON形式でのエクスポート（バックアップ）・インポート（復元）対応
   - 初回サンプルデータへのリセット機能
